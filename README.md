# CompTIA Security+ (SY0-701) Study Hub 🛡️📝

## Project Overview
This repository serves as my central technical repository and documentation notebook for the CompTIA Security+ certification. It maps directly to the five core domains of the SY0-701 exam blueprint, analyzing threat vectors, risk management frameworks, and cryptographic controls.

    *   *Focus:* Risk assessments, third-party vendor governance, business impact analysis (BIA), and privacy compliance standards (GDPR/HIPAA).
